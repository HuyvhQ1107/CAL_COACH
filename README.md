# 🍽️ AI Nutrition Coach

> A Flask web application powered by the **Qwen2-VL-2B-Instruct** vision-language model that analyzes food images and returns detailed nutritional assessments — including calories, macronutrients, vitamins, minerals, and a health evaluation.

## 📖 Overview

**AI Nutrition Coach** is a self-hosted web app that lets users:

1. 📷 **Upload a food image** (a meal, snack, or any dish)
2. 💬 **Ask a question** about it (e.g. *"How many calories are in this food?"*)
3. 🤖 **Receive a structured response** generated by a local multimodal model following a consistent template:
   - Food item identification
   - Portion size & calorie estimation
   - Total calories
   - Macronutrient & micronutrient breakdown
   - Healthiness evaluation
   - Disclaimer

All inference runs **locally** with `Qwen/Qwen2-VL-2B-Instruct` — no external API calls, no data leaves your machine.

---

## ✨ Features

- 🖼️ Drag-and-drop image upload (JPEG / PNG / JPG)
- 🧠 Vision-language understanding powered by Qwen2-VL
- 📋 Structured, consistent output in well-formatted HTML
- 🎨 Clean, responsive web UI with live image preview
- ⚡ Auto-detection of GPU / CPU (`device_map="auto"`, `torch_dtype="auto"`)
- 🗜️ Automatic image resizing to 640×640 for faster inference
- 🔌 Fully local — no third-party API keys required

## 🚀 Getting Started

### 1. Prerequisites

- **Python 3.9+**
- **pip**
- **GPU recommended** (NVIDIA with ≥ 6 GB VRAM). The 2B model uses ~4–5 GB VRAM. CPU is supported but significantly slower.
- ~10 GB free disk space for the model weights and cache.

### 2. Clone the repository

```bash
git clone https://github.com/<your-username>/cal_coach.git
cd cal_coach
```

### 3. Create a virtual environment

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install torch transformers flask pillow accelerate
```

> 💡 **GPU users:** install `torch` with the CUDA wheel that matches your driver first. For example:
>
> ```bash
> pip install torch --index-url https://download.pytorch.org/whl/cu121
> ```

### 5. Run the app

```bash
python app.py
```

Open your browser at **http://127.0.0.1:5000**.

The first run will download `Qwen2-VL-2B-Instruct` from the Hugging Face Hub (~4–5 GB). Subsequent runs are instant.

## 🧠 How It Works

```
┌─────────────┐   image + prompt    ┌──────────────┐
│   Browser   │  ──────────────────▶│   Flask API   │
└─────────────┘                     └──────┬───────┘
                                            ▼
                                  ┌──────────────────────┐
                                  │  base64 → PIL.Image  │
                                  │  resize to 640×640   │
                                  └─────────┬────────────┘
                                            ▼
                          ┌────────────────────────────────────┐
                          │   Qwen2-VL-2B-Instruct             │
                          │   apply_chat_template + generate    │
                          │   max_new_tokens=700, greedy        │
                          └─────────┬──────────────────────────┘
                                    ▼
                         ┌─────────────────────────┐
                         │   Markdown → HTML (regex)│
                         └─────────┬───────────────┘
                                   ▼
                          ┌────────────────┐
                          │   Render UI    │
                          └────────────────┘
```

### Fixed system prompt

The model is guided by `ASSISTANT_PROMPT` in `app.py`, which enforces a six-section response template. Feel free to edit it to suit your use case (e.g. add a section for allergens, glycemic index, etc.).

## ⚙️ Configuration

| Parameter (in `app.py`)        | Default                       | Description                                                       |
| ------------------------------ | ----------------------------- | ----------------------------------------------------------------- |
| `MODEL_ID`                     | `Qwen/Qwen2-VL-2B-Instruct`   | Swap to `Qwen2-VL-7B-Instruct` for higher quality (more VRAM)    |
| `GEN_PARAMS["max_new_tokens"]` | `700`                         | Maximum length of the generated response                          |
| `GEN_PARAMS["do_sample"]`      | `False`                       | Set to `True` for stochastic sampling (more creative responses)   |
| `image.thumbnail(...)`         | `(640, 640)`                  | Increase to `(1024, 1024)` on a strong GPU for sharper vision     |
| `app.secret_key`               | `"change-this-secret-key"`    | **Must be changed** before any production deployment              |

## ⚠️ Important Notes

- 🥗 **Not medical advice.** The calorie and nutrient estimates are approximate. Real values depend on portion size, specific ingredients, preparation methods, and individual variation. For precise dietary guidance, consult a qualified nutritionist or healthcare provider.
- 💾 **VRAM / RAM.** The 2B model needs ~5 GB VRAM on GPU or ~6 GB RAM on CPU. The 7B variant needs considerably more.
- 🔐 **Security.** Replace the default `secret_key` before deploying anywhere public. Do not commit `.env` files or API keys.
